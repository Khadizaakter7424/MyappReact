# PMIT Mini Project (React + TypeScript)

Navbar: Home, About, Contact, PropsData.
Contact page rebuilt from `https://pmit.iitju.edu.bd/contact` (location, helpline, email, office hours, map, socials, message form).

## Run

```bash
npm install
npm run dev
```

Open the printed localhost URL. `npm run build` for production build.

## Structure

```
src/
  App.tsx              routes
  Components/
    Navbar.tsx, Footer.tsx
    Home.tsx / Home.css
    About.tsx
    Contact.tsx / Contact.css
    Propsdata.tsx
    Pro/
      Prop.tsx, Greet.tsx, Greeting.tsx, Trainee.tsx, Container.tsx
```
